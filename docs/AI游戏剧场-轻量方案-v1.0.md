# AI 游戏剧场 · 轻量方案 v1.0

> 2026-08-07 | 目标：一个人、一台电脑，持续产出"一群 AI 玩博弈游戏"的短视频
> 注：此前曾评估"通用博弈编排平台"方案（数十人周级），对内容创作场景过度设计约 10–20 倍，已否决并不再考虑。

---

## 一、先想清楚：爆款视频靠什么

拆解同类爆款（AI 狼人杀 35 万播放、AI 博弈论囚徒困境系列、9 人局做满 20 期的连续剧式账号）后可以发现，观众买单的从来不是"游戏规则多通用"，而是：

1. **戏剧性**：AI 撒谎、背刺、翻车、神操作（"DeepSeek 三狼银水核弹"这类名场面）；
2. **人设**：每个 AI 有名字、头像、性格，观众会"追"某个模型，像追剧一样追角色；
3. **叙事剪辑**：上帝视角 + 解说 + 悬念剪辑，把 2 小时对局压成 5 分钟精华；
4. **系列化**：固定板子、固定"AI 家族"，出新游戏/新板子就是新一季。

**结论：您的核心竞争力在"表现层"（人设 + 呈现 + 剪辑），工程投入应该 70% 花在表现层，30% 花在游戏运行层。** 此前被否决的平台方案恰好把这个比例写反了。

## 二、什么该砍，什么该留

| 过度设计的模块 | 内容创作需要吗 | 处置 |
|---|---|---|
| 可视化节点编辑器（Vue Flow，10 周） | 不需要——您自己会写配置文件 | **砍掉** |
| DSL 编译器 + 三层校验 | 不需要 | **砍掉** |
| 9 原语抽象 + CEL 表达式 | 不需要——游戏逻辑直接写代码 | **砍掉** |
| 模型竞技场 + 统计学（Latin Square、置信区间） | 不需要——观众不要论文要剧情 | **砍掉**（保留"积分/战绩"这种娱乐化呈现） |
| Electron 打包 + utilityProcess 架构 | 不需要——本地网页够用 | **砍掉** |
| 事件溯源回放引擎 | 需要简化版——**这是视频素材的来源** | 保留：每局存一份 JSONL 事件日志 |
| 提示词模板系统（游戏级/角色级/行动级） | 非常需要——人设就是在这里调的 | **保留，且是核心** |
| 可见性过滤（每个 AI 只看到自己该看的） | 需要——不然狼人杀没法玩 | 保留简化版 |
| 结构化输出 + 重试兜底 | 需要——防止 AI 输出乱码毁一局素材 | 保留简化版 |
| 成本追踪 | 非常需要——每期视频有 API 预算 | **保留**（用便宜模型试跑、旗舰模型正式录） |
| Mock Agent 预演 | 需要——新游戏先用假 AI 跑通再花真钱 | 保留 |

## 三、推荐形态：「AI 游戏剧场」= 一个目录一个游戏

不做"平台"，做一个**小游戏运行器 + 回放播放器**。一个游戏就是一个文件夹，换游戏 = 加一个文件夹：

```
games/
  werewolf/
    game.py        # 游戏逻辑：几百行 Python，状态机直接写
    roles.yaml     # 角色配置、人设模板
    prompts/       # 发言/投票/夜行动 prompt 模板
  prisoners/       # 囚徒困境
  avalon/          # 阿瓦隆（下一季素材）
runtime/
  runner.py        # 通用循环：读配置 → 轮流调 LLM → 写事件日志
  llm.py           # 多厂商 API 适配（OpenAI/Claude/Gemini/DeepSeek）+ 重试
  viewer/          # 本地网页：读 JSONL 日志 → 上帝视角回放
```

- **runner 只有约 300 行**：调度回合 → 按可见性拼 prompt → 调 API → 校验输出 → 追加事件日志（JSONL：时间、玩家、动作、发言、内心推理）。
- **viewer 是您真正的护城河**：头像 + 发言气泡/弹幕 + 身份揭示动画 + 倍速/跳转，竖屏 9:16 布局，OBS 直接录屏即素材。
- 换游戏的成本：复制文件夹，写 300–800 行游戏逻辑 + 几套 prompt，1–3 天一个新游戏。

**抽象纪律（防止再次过度设计）**：写满 3 个游戏之前，禁止做任何"通用抽象"；第 3 个游戏写完，把三份代码里真正重复的部分抽出来，那才是您需要的"平台"。

## 四、落地路线（总计 4–7 周出第一个系列）

| 阶段 | 内容 | 工期 |
|---|---|---|
| 第 0 步：先出片 | **不写任何平台代码**。找一个现成开源 AI 狼人杀项目（LLMWereWolf、ai_werewolf、AgentScope 狼人杀示例均可），接入 API，录屏 + 剪辑，发出第一期。目的是验证：您的剪辑风格有没有观众缘 | 1–2 周 |
| 第 1 步：自有运行器 | 写 runner + 狼人杀 game.py + JSONL 日志，人设系统（每个 AI 有名字/性格/说话风格，跨期保持一致） | 2–3 周 |
| 第 2 步：回放播放器 | viewer 网页：上帝视角、头像弹幕、身份动画、竖屏布局。这是之后每一期视频的生产线 | 1–2 周 |
| 第 3 步：第二个游戏 | 囚徒困境或阿瓦隆，验证"1–3 天换游戏"是否成立，顺势开第二季 | 3–5 天 |

成本提示：一期 9 人狼人杀正式录制，用旗舰模型约 $3–8/局；务必先用 DeepSeek 等便宜模型把流程跑到满意，再换旗舰模型录正式版。建议每个 AI 固定绑定一个模型 + 固定人设，观众认脸（"GPT 又是狼"本身就是梗）。

## 五、选题单：不做狼人杀做什么（2026-08 内容生态核实）

狼人杀与囚徒困境已拥挤；博弈论经典游戏的"AI 对战版"基本空白（海盗分金等只有真人讲解形态，几千赞量级）。选题标准：规则 15 秒内能讲清、自带戏剧弧线、动作空间小（好实现）、AI 行为有反差点。

| 优先级 | 游戏 | 内容钩子 | 实现量 |
|---|---|---|---|
| 首选 | 美元拍卖（Dollar Auction） | "为什么 9 个顶级 AI 会花 3 美元抢 1 美元"—— escalation 套牢过程本身就是戏剧 | 极小（竞价循环） |
| 次选 | 海盗分金 | 观众有认知基础；淘汰画面感（喂鲨鱼）；"AI 为什么不按最优解出牌"自带第二话题 | 小（提案+表决+淘汰） |
| 第三 | 最后通牒博弈 | "AI 会为了尊严掀桌子吗"——公平与理性冲突，弹幕天然吵架 | 极小 |
| 备选 | 吹牛骰子 Perudo、胆小鬼博弈、公共品博弈 | 说谎/威慑/搭便车主题轮换 | 小 |

**赛季制包装**：固定 7–9 个 AI 人设阵容，每期一个博弈游戏，积分垫底淘汰，总决赛用多人囚徒困境循环赛收官。差异化定位：狼人杀账号卖"谁是狼"，您卖"AI 的人性实验"。

**对工具的 implication**：这批游戏动作空间极小（出价/提案/投票），单游戏 100–300 行代码，第 3 步"1–3 天换游戏"完全成立；狼人杀反而是最难的那类，不碰它是减负。

## 六、什么时候再回头做"大平台"

满足以下任意两条再考虑另行立项评估：粉丝过 10 万且游戏类型超过 5 个；有广告主/合作方要求定制玩法；您开始带团队，非程序员也要编排游戏。在此之前，专注出片。
